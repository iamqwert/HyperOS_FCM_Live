### 结论与证据
- 依赖核对：`./gradlew :HyperFCMLive:dependencies --configuration releaseRuntimeClasspath/releaseCompileClasspath --offline`
  结果与 `LicensesActivity.DEPS` 的 14 条外部依赖 **完全一致**；唯一未展示的产物是
  `androidx.annotation:annotation-jvm:1.10.0`（KMP 平台别名，与 AndroidX Annotation 同库，故不单列）。
- 因此「多的」= 仓库内自带第三方源码：`hiddenapi/stubs` 下的 AOSP 注解（Apache-2.0）与
  OpenJDK `sun/misc/Unsafe.java`（GPL-2.0 + Classpath Exception，仅编译期，不进 APK）。
  已在 DEPS 中按既有格式补录两条。
- 「冗余的」= 未被引用的 stub：`hiddenapi:bridge` 整模块（R8 usage.txt 中 `bridge.HiddenApiBridge` 被判定未使用）
  + 26 个未被引用的 stub 源文件。精简后 `hiddenapi/stubs` 仅保留 7 个文件
  （Unsafe、android.annotation.NonNull/Nullable、android.content.Context、content.pm.ApplicationInfo、
  android.os.PowerExemptionManager、androidx.annotation.RequiresApi）。
  注意：stubs 模块是纯 `java-library`（无 android.jar 依赖），模块内被引用的 Android 类必须自包含，
  删文件前需确认内部 import 链（PowerExemptionManager → Context → ApplicationInfo）。
